Questions people ask

What is GhostInk?

GhostInk is a free set of three steganography tools that hide secret text or images inside ordinary text and pictures. It runs entirely in your web browser.

Are my files or messages uploaded anywhere?

No. All hiding, revealing and encryption happens locally on your device. GhostInk never sends your text, images or passwords to a server.

What is the difference between steganography and encryption?

Encryption scrambles content so it cannot be read without a key, but it is obvious that something is encrypted. Steganography hides the fact that a message exists at all. GhostInk lets you combine both by adding an optional password that encrypts the message with AES-256-GCM before hiding it.

Will my hidden message survive WhatsApp, Telegram or JPEG compression?

Yes, if you choose the compression-resistant mode. It uses a robust JPEG-friendly method so the hidden data can survive normal photo sharing, as long as the image is not cropped or resized. Plain PNG mode gives full quality but breaks if the image is re-compressed.

How strong is the password protection?

When you set a password, your content is encrypted with AES-256-GCM using a key derived with PBKDF2-SHA256 before it is hidden. If you forget the password the content cannot be recovered.

Does GhostInk work on a phone?

Yes. GhostInk works in any modern mobile or desktop browser with no installation or sign-up.
